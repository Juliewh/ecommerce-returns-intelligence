# E-commerce Returns Intelligence — Аналитика возвратов в электронной коммерции
Комплексный проект по анализу данных, исследованию поведения покупателей и прогнозированию возвратов товаров с помощью машинного обучения.

Возвраты товаров — одна из проблем электронной коммерции, которая может приводить к дополнительным операционным расходам, усложнять управление запасами и влиять на финансовые показатели бизнеса. Интернет-магазину необходимо понять, какие факторы связаны с возвратами товаров и можно ли заранее выявлять покупки с повышенным риском возврата, тем самым сокращать расходы.

В ходе проекта планируется ответить на следующие вопросы:

* Какие категории товаров и ценовые сегменты характеризуются более высокой долей возвратов?
* Как характеристики покупателей и история их покупок связаны с возвратами?
* Какие факторы наиболее тесно связаны с вероятностью возврата товара?
* Как результаты анализа и прогнозирования могут помочь бизнесу принимать более обоснованные решения?

## Цель: исследовать факторы, влияющие на возврат товара, разработать модель машинного обучения для оценки вероятности возврата товара.

## Задачи проекта для достижения цели:

* Провести проверку исходных данных и оценить их качество
* Выполнить очистку и предобработку данных
* Провести исследовательский анализ данных (EDA)
* Определить и рассчитать ключевые бизнес-метрики
* Исследовать взаимосвязи между характеристиками покупателей, товаров и возвратами
* Сформулировать и проверить статистические гипотезы
* Разработать и оценить модель машинного обучения для прогнозирования возвратов
* Интерпретировать результаты модели и определить наиболее значимые признаки
* Создать дашборд и сформулировать практические рекомендации для бизнеса

## Используемый Датасет

Источник: [E-Commerce Returns: Who Will Send It Back? — Kaggle](https://www.kaggle.com/competitions/retail-return-risk-modeling/overview)

Датасет содержит транзакционные данные о покупках за период с 2022 по 2024 год.

### Информация о признаках и целевой переменной:

**Покупатели:**
* ```customer_age``` - возраст покупателя
* ```past_purchase_count``` - количество совершенных покупок
* ```past_return_rate``` - доля возвратов 

**Товары:**
* ```product_price``` - цена товара
* ```discount_percent``` - скидка на товар
* ```product_rating``` - средний рейтинг товара среди покупателей

**Характер сессии:**
* ```session_length_minutes``` - длительность сессии просмотра 
* ```num_product_views``` - количество просмотренных товаров во время сессии просмотра

**Доставка:**
* ```delivery_delay_days``` - количество дней между ориентировочной и реальной датами доставки

**Категориальные признаки:**
* ```device_type``` - девайс, с которого сделан заказ
* ```product_category``` - категория товара
* ```shipping_method``` - вид транспортировки
* ```payment_method``` - тип оплаты
* ```used_coupon``` - был ли использован купон (бинарный)

**Целевая переменная:**
* ```returned``` - был ли возвращён приобретённый товар (1 - возвращен, 0 - оставлен)
